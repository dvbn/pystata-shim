# Security Policy

Treat a `pystata-shim` token as remote-code-execution authority for
the Mac user running the shim.

Please do not publish live tokens, exploit payloads, or host-specific
paths in a public issue. If GitHub private vulnerability reporting is
enabled for the repository, use that. Otherwise, open a minimal public
issue asking for a private reporting channel and omit exploit details
until a maintainer responds.
